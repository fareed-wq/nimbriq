# Nimbriq

Nimbriq is a hands-on AWS Cloud Infrastructure and Terraform learning project.

The goal is to build AWS infrastructure from scratch, understand each cloud component manually, and later recreate the architecture using Terraform Infrastructure as Code.

## Project Goals

- Learn AWS cloud fundamentals
- Understand VPC networking
- Work with compute, storage, IAM, and monitoring
- Apply cloud security best practices
- Learn Terraform Infrastructure as Code
- Build and destroy infrastructure safely
- Maintain a zero-cost learning environment

## Primary AWS Region

Europe (Frankfurt) - `eu-central-1`
